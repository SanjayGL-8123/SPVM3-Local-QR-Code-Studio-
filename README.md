# SPVM3 Local QR Code Studio · Advanced Designer

An advanced, feature-rich offline QR code design studio with a web interface. It runs completely on your local computer, requires zero internet access, and offers professional-grade templates, festive occasion frames, custom shapes, gradients, and brand logos.

---

## 🌟 Features Overview

### 1. Multi-Content Types
- **🌐 Website URL**: Auto-prefixing (`https://`), link validation.
- **📄 Plain Text**: Multi-line messages, notes, and text snippets.
- **📶 Wi-Fi Network**: Network SSID, Password, Encryption (WPA/WPA2/WPA3, WEP, Open), and Hidden SSID support.
- **👤 Contact Card (vCard 3.0)**: First & last name, company, job title, mobile & office phone, email, website.
- **✉️ Email**: Recipient address, subject line, and pre-filled message body.
- **📞 Phone Call**: Direct telephone number dialing.
- **💬 SMS**: Recipient number and pre-composed SMS text.
- **📱 WhatsApp**: Direct chat link with international phone number and pre-filled message.

## 🚀 How to Run

### Requirements
- Windows 10 or 11
- Python 3.10 or newer (Make sure **Add Python to PATH** is ticked during installation)

### Run from Source
1. Open Command Prompt or PowerShell in this project folder:
   ```bat
   python -m pip install -r requirements.txt
   python app.py
   ```
2. Your default web browser will automatically open at `http://127.0.0.1:<port>/`.

### Build a Standalone Windows EXE
1. Double-click `build_windows.bat`.
2. The script detects Python, installs PyInstaller, packages the templates, and produces:
   ```
   dist\SPVM3LocalQRStudio.exe
   ```
3. Run `SPVM3LocalQRStudio.exe` directly on any Windows PC without needing Python installed!

## 🔒 Security & Privacy
- **Localhost Only**: Binds strictly to `127.0.0.1`.
- **100% Offline**: No telemetry, no external API calls, and no data leaves your computer.
